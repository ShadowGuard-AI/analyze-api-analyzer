analyze-api-analyzer

Examines API endpoints, from Swagger and OpenAPI definitions or live endpoints, for common vulnerabilities like missing authentication or rate limiting issues.

Open the repo Usage

What it checks

  • Missing authentication on endpoints
  • Rate limiting issues

It works from a Swagger or OpenAPI definition, or against live endpoints, and uses requests and json for API interaction and definition parsing. It can fetch a definition from a URL, sending an optional authentication header with the fetch.

Install and usage

cd analyze-api-analyzer
pip install -r requirements.txt

./analyze-api-analyzer [params]

Dependencies are in requirements.txt: pandas and requests.

Parameters

-hshow help message and exit
--outputno description provided in the source; the blank is left showing rather than filled with an invented duty
--auth_headerheader to send when fetching a definition from a URL: a full "Name: Value" header, or an Authorization value such as "Bearer <token>". A credential travels with this fetch, so the header is named in full rather than shortened.
--verboseno description provided in the source; the blank is left showing rather than filled with an invented duty
